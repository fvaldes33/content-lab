# Production Brief

Reframed 2026-08-16 after Franco's review. The original four-source taxonomy ("where did ChatGPT get that?") was accurate but flat: it explained mechanisms without giving the viewer anything to do, and it was scoped to ChatGPT only. This version is failure-first, covers ChatGPT and Claude, and pays off with three concrete fixes plus one documented gotcha. The four-source model survives as the internal skeleton and a candidate follow-up post.

## Viewer and promise

- **Target viewer:** A regular ChatGPT or Claude user who has been burned by memory in both directions — it dredged up something oddly personal, or it forgot an instruction they gave minutes earlier — and doesn't know these are different, fixable problems.
- **Question or situation:** "Why does my AI remember weird things and forget important ones, and what am I supposed to do about it?"
- **One-sentence promise:** In about a minute, turn three familiar memory failures into three specific fixes that work in both ChatGPT and Claude.
- **Why it matters now:** Both vendors overhauled memory in 2025–2026 (ChatGPT's synthesized Memory; Claude's categorized, editable memory entries, now on all plans). Most users' mental model — "a notepad it writes to" — no longer matches either product.

## Angle

- **Strongest honest hook:** "ChatGPT can remember your dog's name from three months ago — and forget the instruction you just gave it. Claude does the same thing."
- **Core claim:** Your AI has two memories — a synthesized long-term profile and this-chat working context — and each failure people complain about belongs to one of them and has a specific fix.
- **Practical takeaway:** Restate constraints in long chats (or start fresh); keep one-offs in Temporary/Incognito chat and edit the memory page; pin critical context in Custom Instructions or a Claude Project. And deleting a chat doesn't delete what was learned from it — that's a separate step.
- **Franco's credible angle:** An engineer explaining failure modes the way he'd debug a system — mechanism, then fix — across both products he actually uses, instead of product tips for one app.
- **What a generic AI account would miss:** That the failures have different mechanisms (context degradation vs. synthesis pollution vs. lossy summarization), that the fixes are documented product controls rather than prompt hacks, and that the delete-chat gotcha is symmetrical and official in both products.

## Production

- **Primary format:** 60–75 second Reel: talking head plus tight screen crops of both products' memory controls and one simple two-memory diagram.
- **Production tier and time cap:** STANDARD, 90 minutes total: 15 minutes captures across both products, 15 minutes recording, 40 minutes edit/captions, 10 minutes final review, 10 minutes publishing and logging.
- **Call to action, if useful:** No engagement CTA. End on the practical instruction: "Go check your memory page." Caption supplies both settings paths.
- **Reusable proof artifact:** A two-column "TWO MEMORIES" diagram (LONG-TERM: profile, synthesized / THIS CHAT: working context, finite) reusable in follow-ups.

## Claim boundary

- **Verified:** Both products synthesize long-term memory from ordinary chats; both memory views are documented as incomplete; Temporary Chat and Incognito chat exclude conversations from memory; Claude Projects have separate memory; long-context research shows middle-of-context degradation; deleting a chat does not delete derived memories in either product.
- **Firsthand observation to produce:** Current plan, surface, memory setting state, and visible memory experience for Franco's ChatGPT and Claude accounts; privacy-safe captures of each control shown.
- **Inference or opinion:** The two-memory framing and the three-failure grouping are Franco's explanatory model; "restate the rule or start fresh" is engineering practice motivated by research, not a vendor instruction.
- **Uncertain or contested:** Consumer context-assembly behavior in both products; which memory experience (legacy vs. current) any viewer sees mid-rollout; Claude consumer-plan incognito retention duration (unstated in the source — make no claim).
- **Claims this post must not make:** That the middle of a chat is always lost; that memory pollution provably happened to a specific person (the resume example is an illustrative hypothetical); that Temporary/Incognito chats are anonymous or zero-retention; that the memory page shows everything; that deleting chats scrubs the profile; that ChatGPT and Claude memory are identical; any token-limit number.
