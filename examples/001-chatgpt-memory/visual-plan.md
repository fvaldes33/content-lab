## Two-memory diagram copy

```text
YOUR AI HAS TWO MEMORIES

LONG-TERM                 SHORT-TERM
profile from your chats   this conversation
fails: stale, incomplete  fails: blurry middle
```

Keep it visually plain: one neutral background, two outlined columns, one accent color. No brains, no databases, no animated data flows.

## Capture checklist

- [ ] Privately log, for each product: date, plan, surface, model/mode, memory setting state, and which memory experience is visible (legacy vs. current).
- [ ] ChatGPT: tight crop of Settings → Personalization → Memory — headings and controls only, personal contents cropped, blurred, or absent.
- [ ] Claude: tight crop of Settings → Memory — category headings visible, entry contents cropped or synthetic.
- [ ] ChatGPT: Temporary Chat control. Claude: ghost icon on a new chat.
- [ ] Optional: ChatGPT Custom Instructions (empty/synthetic) and a Claude Project view (synthetic project name).
- [ ] Synthetic long-chat capture for Failure 1 — only demo content, no real work.
- [ ] Do not create real memories, delete real chats, or expose account name, email, chat titles, files, or connected apps in any frame.
- [ ] Record talking-head sections in two or three continuous takes (camera mode only).
- [ ] Add burned-in captions from the clean script — never from the tagged VO script.
- [ ] Recheck every frame for personal information before export.

## Editing restraint

- **Visual evidence that is essential:** The two-memory diagram, one memory-settings crop per product, and the kicker card.
- **Visual polish that can be skipped:** Custom icons, side-by-side synchronized comparisons, animated transitions, branded intro/outro, and a bespoke illustration.
- **Fallback if an asset takes too long:** Any screen capture can drop to its on-screen text card; the entire post works as talking head (or VO over cards) with six text overlays.
