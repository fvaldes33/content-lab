# Brand

The brand this repo makes content for, shared by every skill: the social pipeline reads
the voice and product truth, the video studio renders in the tokens and assets.

| File | What it holds |
|---|---|
| `brand.ts` | Typed tokens: colors, fonts, logo/icon paths, motion pace, positioning, proof points, default CTA. Pure data. |
| `product.md` | Product truth and the claim boundary: what the product really does, named features, real UI labels, what we must not claim. |
| `voice.md` | How the brand sounds and what it never says. |
| `visual-language.md` | Look and feel beyond tokens: surfaces, imagery, what to avoid. |
| `assets/` | Logo, app icon, local font files, real product screenshots. |

It ships as **Acme Planner**, a fictional placeholder so the example video renders out of
the box. Run `/onboard` (the brand batch) to replace it with your real product; until
then, nothing here should be treated as true about any real company.
